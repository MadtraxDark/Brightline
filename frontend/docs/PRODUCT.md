# Brightline

Aplicação para acompanhar achados em laudos médicos. O usuário descreveu o produto como um sistema de laudos e forneceu logo, ícone e referência de dashboard SaaS.

Usuários previstos: profissionais clínicos que revisam laudos e acompanham encaminhamentos. Fluxo existente: selecionar caso, ler laudo, confirmar leitura, registrar ação e fechar caso. A IA destaca uma evidência; a decisão é humana.

A implementação usa React e Vite. A API em src/api.js está em modo mock. As estatísticas e os casos são dados demonstrativos; não representam uma instituição conectada. Há simulação de passagem de tempo e escalações.

Prioridade de experiência explicitada pelo usuário: clareza, menos informação simultânea e organização familiar de SaaS. Preservar conteúdo clínico e funcionalidades durante mudanças visuais.
